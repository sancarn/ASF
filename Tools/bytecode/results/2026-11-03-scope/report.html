Validation and limitations

All three modes pass 254/255 upstream tests. The same pre-existing nested-array VBAExpressions failure remains (42 expected / 8 actual). Routing counts are invocations, not test cases. Verbose and host-sensitive upstream tests use the shared-scope path. Separate targeted tests assert actual lowering as well as value/type parity.

Compile measures AST parsing. Bytecode lowering occurs on first Run and is included in the cold execution phase. Validation and Python/COM communication are outside timed batches. Input arguments are materialized identically in all modes. Synthetic materials/payroll workloads contain no proprietary SGBO data.
